# Handoff & Changelog Maintenance Protocol

1. **Session Orientation**:
   - At the start of a new complex task, consult `.agent/HANDOFF.md` and `.agent/ARCHITECTURE.md` to understand current deployment state, recent changes, and architectural boundaries.

2. **Continuous Documentation**:
   - After completing any significant feature, architectural change, or deployment:
     1. Append a dated entry to `.agent/CHANGELOG.md` detailing Added, Changed, and Fixed items with file links.
     2. Update `.agent/HANDOFF.md` to reflect the latest completed work, current test/build status, and updated backlog priorities.
